# LABS — nueva web mejorada

Versión estática preparada para GitHub Pages.

## Archivos
- `index.html`
- `styles.css`
- `script.js`

## Publicar en GitHub Pages
1. Crear un repositorio público, por ejemplo `labs-ec`.
2. Subir estos tres archivos a la raíz.
3. Ir a `Settings` → `Pages`.
4. En `Build and deployment`, elegir `Deploy from a branch`.
5. Branch: `main`; Folder: `/ (root)`.
6. Guardar y esperar la publicación.

## Nota
La interfaz es una propuesta independiente. Los enlaces hacia resultados, cotizador, servicios, nosotros, preguntas frecuentes y selección apuntan a recursos de LABS existentes. El formulario/backend de la web actual no se reemplaza porque esta versión es una nueva interfaz estática.
